# 角色素材生成提示词

## 通用约束

所有角色精灵图必须遵守同一套格式，避免导入游戏后错位或变形：

- 输出一张 `4 x 4` 精灵表，透明背景。
- 推荐尺寸 `128 x 128` 像素，每帧 `32 x 32` 像素。
- 也可以生成更高清的正方形图，例如 `1024 x 1024`；游戏会按 `4 x 4` 自动裁切并缩放到 `32 x 32`。
- 四列从左到右依次是：待机、移动帧 1、移动帧 2、攻击。
- 四行从上到下依次是：朝下、朝左、朝右、朝上。
- 不要边框、不要网格线、不要文字标签、不要水印。
- 每帧角色保持同一比例、同一锚点、同一脚底基准线。
- 角色必须完整留在单帧内，不要武器、披风、特效越格。
- 风格为清晰像素风，深色描边，高对比，适合 32 像素小尺寸阅读。
- 游戏内所有可见文字必须使用中文；素材图本身不要出现任何文字。

通用负面提示词：

```text
文字，英文，标签，水印，边框，网格线，白底，复杂背景，阴影溢出格子，角色被裁切，比例不一致，锚点漂移，抗锯齿过强，模糊边缘，写实照片，厚涂插画，3D渲染，等距透视，武器越过单帧边界
```
